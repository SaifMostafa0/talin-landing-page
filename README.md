# Talin Landing Page

The primary Talin website, built with React, TypeScript, TanStack Start, Tailwind CSS, and Vite.

## Development

```sh
npm install
npm run dev
```

The development server runs from the repository root.

## Validation

```sh
npm run lint
npm run build
```

## Project structure

- `src/routes/index.tsx` — landing page content and composition
- `src/styles.css` — Talin design tokens and visual system
- `src/assets/` — web-ready logo assets
- `talin-assets/` — source brand documents, logo exports, and website guidelines
- `lovable-version/` — retained copy of the originally supplied Lovable export
